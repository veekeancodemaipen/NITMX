# ทะเบียนกรณีและการตรวจเอกสารเดิม

หน่วยวิเคราะห์คือ **โพสต์/หน่วยรายงาน** ไม่ใช่บุคคล บัญชี หรือคดีที่พิสูจน์แล้ว กรณีเดิม 50 หน่วย (M01–M30 และ H01–H20) เก็บโดยผู้รวบรวมเมื่อ 19 ก.ย. 2569; งานนี้อ่านจาก Markdown ทั้งสองไฟล์ ไม่ได้กลับไปยืนยันโพสต์สด กรณีสาธารณะเพิ่ม 4 หน่วย (P01–P04) เลือกเพื่อเติมตัวอย่างปฏิเสธ แรงกดดัน เจ้าของร่วมทำ และหลักฐานคดี

**สถานะคัดเลือก:** main = ใช้สังเคราะห์ประเด็น, context = บริบท/ข้อมูลไม่พอเชื่อมตรง, exclude = ไม่นำไปสรุปกลไกบัญชีม้า แต่เก็บเพื่อให้เห็นการตัดออก กรณีเดิม main 40, context 8, exclude 2; กรณีใหม่ main 2, context 2 ตัวเลขนี้บอกการจัดเอกสารเท่านั้น

ชื่อบุคคล บัญชีติดต่อ และชื่อผู้ช่วยคดีถูกตัดออกจากทะเบียนใหม่ การจัดกลุ่มไม่วินิจฉัยความผิด/ความบริสุทธิ์ ไม่ตีความความต้องการขายเท่ากับรู้วัตถุประสงค์อาชญากรรม ไม่ตีความการอายัดเท่ากับขายบัญชี ภาพที่ถูกกล่าวถึงไม่ได้แนบให้ตรวจผูกกรณีอย่างชัดเจน ไม่ได้ตรวจนิติวิทยาศาสตร์ของภาพ

**ธงข้อมูลอาจซ้ำ:** H07 และ H20 ใช้ชื่อแสดงผลเดียวกันในหัวข้อต้นฉบับ จึงอาจเป็นผู้โพสต์รายเดิม แต่ไม่ยืนยันตัวบุคคลหรือว่าเป็นเหตุการณ์เดียวกัน เก็บสองหน่วยโพสต์และไม่ตีความเป็นสองคน
